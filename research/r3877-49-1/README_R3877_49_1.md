## Why this is needed

The user-reported real R3877.49 Colima run executed QEMU 10.0.4 and then ran the ARMv7 BusyBox `true` syscall-trace probe. Its guest **exit code was 0** and the trace parser recognised **655 syscall records / 9 distinct names**, with zero trace `ENOSYS` or unknown-syscall records. However, the program-output SHA-256 was **not empty**, so the strict `true` output check correctly returned `HOLD` (wrapper exit 2). The cause and actual unclassified text were not available in that output. Zero `ENOSYS` entries observed in this very narrow QEMU run is **not** evidence of compatibility with the PW3's Linux `3.0.35-lab126` kernel.

The default QEMU `-strace` parser separates strings that match a syscall-record format from all other output. This distinction is important because QEMU user-mode trace output is not identical to host `strace`, and lines may be formatted in unexpected ways. We must not silently drop lines or claim they were harmless.

## R3877.49.1 scope

A standalone derivative of R3877.49 retains the **same** cached parent Alpine image ID, pinned QEMU/BusyBox hashes, read-only-first Docker copy test, explicit disposable writable fallback, guest `argv` verification, absence of network/host mounts, UID 65534:65534, dropped capabilities, no-new-privileges, 256 MB/64 PID limits, readback verification, Docker diff allowlist, exact-container cleanup and parent-image unchanged verification. It does **not** add a permission or an additional guest workload.

The **only** functional difference is additional bounded and redacted *diagnostic metadata* for unexpected output:

- Counts of unmatched output lines by stdout/stderr channel, plus total residual byte count.
- Up to **eight** samples with each line's SHA-256, byte length, character-class shape (letters, digits, whitespace, punctuation without original characters), and broad parsing category.
- The actual program-output hash and boolean exact-output-match test remain enforced. Any unknown or unexpected output still returns `HOLD`.

It never prints arbitrary unclassified lines, paths, pointer values or syscall arguments. When reported to ChatGPT, send only the JSON result, not unredacted container logs. The captured trace remains imperfect QEMU **host-translated** syscall observation; it is **not** a target-kernel or musl fallback validation.
