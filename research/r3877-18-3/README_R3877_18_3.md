# R3877.18.3 — Read-only ARM ELF provider symbol-type audit

**For research and educational purposes only.** The Kindle remains `NOT_BOOTABLE`; there is no authorization to boot, flash, install or replace binaries or alter firmware. This is not a rescue image.

## User-reported evidence

R3877.18.2 parsed 38 KOReader and seven stock system ELF files. It classified all 167 original strict-scope candidate misses into **163 Lua API exports found in the main `luajit` executable** and **four type mismatches for `clock_gettime@GLIBC_2.4` attributed to `librt.so.1`**. This was a static classification, not evidence of runtime linking or correct `dlopen`/load order.

## Goal of this test

R3877.18.3 retrieves exactly the same fixed 45-file ELF subset using one authorized SSH session and inspects each of the four `clock_gettime` provider export *symbol types*. It reports function/object, GNU IFUNC and ARM Thumb-function types without changing the previous baseline counts. GNU IFUNC and ARM Thumb-function labels are **conditional metadata**, not proof that a relocation will succeed. This diagnostic also reads the ELF file type (ET_EXEC vs ET_DYN) of the existing main LuaJIT executable; it does not validate Lua module `dlopen` order.

- `STT_FUNC` is ELF symbol type 2.
- `STT_GNU_IFUNC` is type 10 and indicates a resolver evaluated by the dynamic linker, which **is not executed** by this test.
- `STT_ARM_TFUNC` is the ARM-specific type 13, reported separately rather than assumed to be compatible.
- Other symbol-type mismatches remain unverified; the script does not recast them as a pass in runtime binding.

The live analyzer refuses a changed R3877.18.2 167/163/4 baseline, malformed ELF metadata, uncollected needed dependencies and unexpected provider names. A read-only, no-archive `--probe-ssh-only` mode is retained. Collection never includes books, settings or personal files. No target binary is installed/executed; the only target commands are existing shell tools for reading and archiving fixed files. The archive is analyzed in memory on the Mac.

The expected classification is `PASS_PROVIDER_TYPE_METADATA_ONLY` and exit 0, **provided the live ELF snapshot matches the historical baseline**. A changed baseline or a parsing error produces `HOLD` and exit 2. On a sleeping Kindle, use `--probe-ssh-only` to test SSH without transferring the archive.

## Limitations

`NOT_BOOTABLE` is immutable. This audit does not prove runtime ELF binding, GNU IFUNC resolver operation, `dlopen` visibility, main executable symbol scope, soft-float glibc library closure, Alpine hard-float musl compatibility, Linux 3.0.35 syscalls/TLS, original R13 provenance or recovery. It never claims device changes or live test success from offline tests.
