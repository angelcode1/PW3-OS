## Change

This release preserves the exact ARMv7 and AArch64 binaries and unchanged R49.3 QEMU isolation runner. Helper and preparation containers are now explicitly created as **read-only, unprivileged UID 65534:65534, capability-drop-all, `no-new-privileges`, networkless, PID/memory-limited** stopped guests. Their inspect results are evaluated against **17 separate checks**, including image identity, stopped state, mounts, devices, default seccomp not overridden, and policy matching. Any mismatch is a **HOLD**. The report includes only boolean check results and stable failure names in `auxiliary_container_isolation.helper` and `.preparation`, not raw inspect output or container IDs.

All the original QEMU runtime, pinned byte hashes, read-only copy probe, explicit disposable writable fallback, trace and cleanup gates remain intact. **If the helper failure repeats, report the failed check names; do not change Docker settings or bypass security.** New runtime success is not presumed.
